# 陈家曦个人网站 GitHub Pages 版本

这个文件夹可以直接上传到 GitHub Pages。

## 最推荐的发布方式

1. 登录 GitHub。
2. 新建一个公开仓库，仓库名写成：

   `你的GitHub用户名.github.io`

   例如你的用户名是 `chenjiaxi`，仓库名就是：

   `chenjiaxi.github.io`

3. 把本文件夹里的所有文件上传到仓库根目录：

   - `index.html`
   - `styles.css`
   - `README.md`

4. 打开仓库的 `Settings` -> `Pages`。
5. Source 选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/root`。
7. 等待 GitHub Pages 部署完成。

部署成功后，网站地址通常是：

`https://你的GitHub用户名.github.io`

## 如果你不想用用户名主页仓库

也可以新建普通仓库，例如：

`personal-site`

这种情况下网站地址通常是：

`https://你的GitHub用户名.github.io/personal-site/`
